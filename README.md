# Actividad 1: Programación Web

## Descripción
Este proyecto contiene una serie de ejercicios prácticos de HTML y CSS desarrollados como parte de la actividad de programación web. La finalidad es reforzar el uso de etiquetas, estructura de documentos, diseño visual, enlaces, formularios, tablas y elementos interactivos básicos.
El proyecto se presenta a través de una página principal llamada `index.html`, desde la cual se accede a cada ejercicio individual.

## Objetivo de la actividad
Aprender y practicar los fundamentos del desarrollo web front-end mediante:
- Estructura correcta de documentos HTML.
- Uso de títulos, párrafos, listas y enlaces.
- Integración de imágenes y contenido multimedia.
- Organización de secciones y diseño básico con CSS.
- Creación de formularios y páginas de contacto.
- Desarrollo de pequeñas aplicaciones web con lógica simple.

## Estructura del proyecto
- `index.html` — página principal (menú) con acceso a todas las actividades.
- `ejercicio1.html` al `ejercicio10.html` — ejercicios individuales.
- `CSS/` — hojas de estilo utilizadas por los ejercicios y el menú.
- `img/` — recursos gráficos e imágenes del proyecto.
- `JS/` — scripts interactivos de los ejercicios.

## Ejercicios incluidos
- `ejercicio1.html` — presentación básica con “Hola Mundo”
- `ejercicio2.html` — primera página con formato y estilo visual
- `ejercicio3.html` — práctica con enlaces y navegación
- `ejercicio4.html` — uso de imágenes y contenido visual
- `ejercicio5.html` — creación de un blog personal
- `ejercicio6.html` — organización por secciones de una página web
- `ejercicio7.html` — receta de tacos al pastor
- `ejercicio8.html` — horario escolar con diseño de tabla
- `ejercicio9.html` — formulario o página de contacto
- `ejercicio10.html` — calculadora de temperatura en Fahrenheit

## Cómo visualizar el proyecto
1. Abre la carpeta del proyecto en tu navegador o accede a través del enlace de GitHub Pages.
2. Ejecuta/visualiza el archivo `index.html`.
3. Selecciona cualquiera de las opciones del menú para ver el funcionamiento de cada ejercicio.
